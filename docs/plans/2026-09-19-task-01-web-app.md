# Task 01 — Apogee: Creative, API-Integrated Web App — Implementation Plan

> **Status: AWAITING APPROVAL.** Nothing further gets built until this document is approved.

**Goal:** Ship a polished, single-purpose web app that lets anyone travel to any date since 16 June 1995 and see the photograph NASA published of the universe that day — backed by our own Next.js backend-for-frontend that hides the API key, caches by immutability, and survives NASA's rate limiting.

**Architecture:** A Next.js App Router application where every call to NASA happens on the server. The browser never holds an API key and never talks to `api.nasa.gov`. Server Components render the focal plate; a single route handler (`/api/apod`) serves the archive grid's "load more" requests. The selected date lives in the URL, so every view is a shareable link.

**Tech Stack:** Next.js 16.3.5 (App Router) · React 19.2.8 · TypeScript 5 · Tailwind CSS v4 · `motion` · `server-only` · deployed on Vercel.

## Design Direction (locked)

**Concept:** An observatory plate catalogue. Each APOD is an archival photographic plate with an index number, a filing date, and a credit line — not a card in a feed.

**Why not the obvious choice:** The default for a space app is a purple-black gradient with glowing stars and a neon accent. That look appears regardless of subject. This direction is drawn from the *materials of a plate archive* instead: the blue-black of a night exposure, the warm cream of aged photographic paper, the amber of a darkroom safelight, the pale cyan of a negative.

**Signature element:** The loading state *is* the signature. An image arrives as an undeveloped plate — dark, grainy, with a safelight sweeping across it — and then resolves through blur, saturation, and brightness into the finished photograph, exactly as a plate resolves in a developing bath. This satisfies the brief's "skeletons and shimmers, not just a spinner" requirement and the aesthetic signature in one move, which is why no other decorative motion is added.

**Restraint:** One bold idea (the develop reveal). Everything else — type, spacing, borders — stays quiet and disciplined.

**Type roles:** Fraunces (display, plate titles) · Geist Sans (prose) · Geist Mono (all measured data: dates, plate numbers, medium, credit).

**Copy voice:** Observatory catalogue. Plain and factual. Errors give directions, never apologies. "No plate was filed for this date", not "Oops! Something went wrong."

- [ ] **Step 0: Split `posterImage` out of the server-only module**

`nasa.ts` starts with `import "server-only"`, which makes importing it from any Client Component a build error. That guard is the whole point — but `posterImage()` is a pure function the archive grid needs on the client. It has to live somewhere neutral.

Create `src/lib/plates.ts`:

```ts
import type { Apod } from "./types";

/**
 * The best still image for a plate.
 *
 * Lives outside the server-only BFF because both the server-rendered focal
 * plate and the client-rendered archive grid need it. It touches no secret and
 * makes no network call, so sharing it costs nothing.
 *
 * Video entries have no `url` image at all; NASA supplies `thumbnail_url` only
 * because the request asked for thumbnails. Returning null lets the UI render a
 * deliberate placeholder instead of a broken image.
 */
export function posterImage(plate: Apod): string | null {
  if (plate.media_type === "image") return plate.url ?? null;
  return plate.thumbnail_url ?? null;
}
```

Then delete the `posterImage` export from the bottom of `src/lib/nasa.ts`, and update `src/components/focal-plate.tsx` to import it from `@/lib/plates` instead of `@/lib/nasa`.

```tsx
"use client";

import Link from "next/link";
import { useState } from "react";

import { formatIndexDate, plateNumber, precedingWindow } from "@/lib/dates";
import { posterImage } from "@/lib/plates";
import type { Apod } from "@/lib/types";

import { EmptyNotice } from "./notices";
import { PlateImage } from "./plate-image";

const PAGE_SIZE = 12;

type ArchiveStripProps = {
  focalDate: string;
  initialPlates: Apod[];
};

/**
 * The plates filed immediately before the one in focus.
 *
 * The first page is rendered on the server so the grid is never empty on
 * arrival. Further pages are fetched from our own route handler, which means
 * the browser still never learns the NASA key or talks to NASA directly.
 */
export function ArchiveStrip({ focalDate, initialPlates }: ArchiveStripProps) {
  const [plates, setPlates] = useState(initialPlates);
  const [status, setStatus] = useState<"idle" | "loading" | "exhausted">("idle");
  const [failure, setFailure] = useState<string | null>(null);

  const oldest = plates.at(-1)?.date ?? focalDate;

  async function loadOlder() {
    setStatus("loading");
    setFailure(null);

    const { start, end } = precedingWindow(oldest, PAGE_SIZE);
    if (end < start) {
      setStatus("exhausted");
      return;
    }

    try {
      const response = await fetch(`/api/apod?start=${start}&end=${end}`);
      const body = await response.json();

      if (!response.ok) {
        setFailure(body?.error?.detail ?? "The archive could not be read.");
        setStatus("idle");
        return;
      }

      const older: Apod[] = body.plates ?? [];
      if (older.length === 0) {
        setStatus("exhausted");
        return;
      }

      setPlates((current) => [...current, ...older]);
      setStatus("idle");
    } catch {
      setFailure("Could not reach the archive. Check your connection.");
      setStatus("idle");
    }
  }

  if (plates.length === 0) {
    return (
      <section className="mt-16">
        <SectionHeading />
        <EmptyNotice message="No earlier plates are on file for this range" />
      </section>
    );
  }

  return (
    <section className="mt-16">
      <SectionHeading />

      <ul className="mt-6 grid grid-cols-2 gap-px border border-plate-edge bg-plate-edge sm:grid-cols-3 lg:grid-cols-4">
        {plates.map((plate) => (
          <li key={plate.date} className="bg-plate-black">
            <Link
              href={`/?date=${plate.date}`}
              scroll={false}
              className="group block focus-visible:outline-offset-[-2px]"
            >
              <div className="relative aspect-square">
                <PlateImage
                  src={posterImage(plate)}
                  alt={plate.title}
                  isVideo={plate.media_type !== "image"}
                  sizes="(min-width: 1024px) 280px, (min-width: 640px) 33vw, 50vw"
                />
              </div>
              <div className="flex flex-col gap-1 p-3">
                <span className="font-mono text-[10px] uppercase tracking-[0.2em] text-cyanotype">
                  {formatIndexDate(plate.date)} · {plateNumber(plate.date).toLocaleString("en-GB")}
                </span>
                <span className="line-clamp-2 font-display text-sm leading-snug text-emulsion/85 transition-colors group-hover:text-safelight">
                  {plate.title}
                </span>
              </div>
            </Link>
          </li>
        ))}
      </ul>

      {failure && (
        <p role="alert" className="mt-4 font-mono text-[11px] uppercase tracking-[0.18em] text-safelight">
          {failure}
        </p>
      )}

      <div className="mt-6 flex justify-center">
        {status === "exhausted" ? (
          <p className="font-mono text-[10px] uppercase tracking-[0.25em] text-graphite">
            End of the archive
          </p>
        ) : (
          <button
            type="button"
            onClick={loadOlder}
            disabled={status === "loading"}
            className="rounded-sm border border-plate-edge px-6 py-3 font-mono text-[11px] uppercase tracking-[0.2em] text-graphite transition-colors hover:border-safelight/50 hover:text-emulsion disabled:opacity-50"
          >
            {status === "loading" ? "Retrieving…" : "Load earlier plates"}
          </button>
        )}
      </div>
    </section>
  );
}

function SectionHeading() {
  return (
    <h2 className="font-mono text-[10px] uppercase tracking-[0.25em] text-graphite">
      Preceding plates
    </h2>
  );
}
```

```tsx
import { DateNavigator } from "@/components/date-navigator";
import { FocalPlate } from "@/components/focal-plate";
import { ArchiveStrip } from "@/components/archive-strip";
import { ErrorNotice } from "@/components/notices";
import { SiteHeader } from "@/components/site-header";
import { clampToArchive, isValidDateString, precedingWindow, todayInArchiveTime } from "@/lib/dates";
import { getPlate, getPlateRange } from "@/lib/nasa";

const ARCHIVE_PAGE_SIZE = 12;

/**
 * The archive, composed on the server.
 *
 * The date comes from the URL, which makes every view addressable. An invalid
 * or out-of-range date silently falls back to today rather than erroring: a
 * bad link should still show someone the cosmos.
 */
export default async function ArchivePage({
  searchParams,
}: {
  searchParams: Promise<{ date?: string }>;
}) {
  const { date: requested } = await searchParams;

  const focalDate =
    requested && isValidDateString(requested)
      ? clampToArchive(requested)
      : todayInArchiveTime();

  const window = precedingWindow(focalDate, ARCHIVE_PAGE_SIZE);

  // Both requests go out together; the grid must not wait on the focal plate.
  const [plateResult, archiveResult] = await Promise.all([
    getPlate(focalDate),
    getPlateRange(window.start, window.end),
  ]);

  return (
    <div className="mx-auto w-full max-w-[1120px] px-5 py-8 sm:px-8 sm:py-12">
      <SiteHeader />

      <div className="my-8 flex flex-col gap-4 sm:my-10">
        <p className="max-w-[46ch] text-sm leading-relaxed text-graphite">
          Every day since 16 June 1995, NASA has published one photograph of the
          universe. Travel to a date and see the one from that day.
        </p>
        <DateNavigator date={focalDate} />
      </div>

      {plateResult.ok ? (
        <FocalPlate plate={plateResult.data} />
      ) : (
        <ErrorNotice error={plateResult.error} />
      )}

      <ArchiveStrip
        focalDate={focalDate}
        initialPlates={archiveResult.ok ? archiveResult.data : []}
      />

      <footer className="mt-20 border-t border-plate-edge pt-6">
        <p className="font-mono text-[10px] uppercase tracking-[0.22em] text-graphite">
          Images courtesy NASA APOD ·{" "}
          <a
            href="https://apod.nasa.gov/apod/astropix.html"
            target="_blank"
            rel="noreferrer noopener"
            className="text-safelight transition-colors hover:underline"
          >
            Source archive ↗
          </a>
        </p>
      </footer>
    </div>
  );
}
```

The API quirks section must document these, all of which were hit during the build:

| Quirk | Handling |
|---|---|
| NASA publishes on US Eastern time, so "today" in UTC+4 can 404 | All "today" computed in `America/New_York` |
| `media_type` can be `video`, which has no image | `thumbs=true` requests a poster; UI marks it "motion plate" |

| The archive starts 1995-06-16; earlier dates return 400 | Validated before a request is spent |
| `DEMO_KEY` is capped at 30 req/hour/IP | Dual-TTL cache + retry with backoff; documented in `.env.example` |

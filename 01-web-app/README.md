# Apogee — Task 1 planning handoff

Apogee is a proposed date-addressable observatory archive built around NASA's Astronomy Picture of the Day API.

**Current state:** planning and audit are complete; implementation is in progress. A composed archive page now exists, but its upstream adapter, accessibility, media semantics, verification evidence, and delivery material still need correction before submission.

Start with [docs/00-START-HERE.md](docs/00-START-HERE.md). It links the product and UI specification, backend contract, revised implementation plan, strict verification matrix, delivery runbook, and video and interview notes.

The executable plan is [../docs/plans/2026-09-19-task-01-web-app.md](../docs/plans/2026-09-19-task-01-web-app.md).

No real credentials belong in this repository. The final project requires a server-side `NASA_API_KEY`, a tracked placeholder-only `.env.example`, a live deployment, a build log, and fresh verification evidence.
